
# PixHelado

PixHelado is a lightweight pixel-art drawing tool built with Godot Engine 4.3
It focuses on simplicity, speed, and a clean workflow for creating small sprites, icons, and pixel-based assets.


## Features

- Pixel-art canvas
- Basic drawing tools (brush, eraser, fill, etc.)
- Image export options for PNG, JPG and WEBP
- Project saving and loading using PXHELADO format
- Lightweight and fast to load

## How to run
1. Download Godot version 4.3 stable --> https://godotengine.org/download/archive/4.3-stable/
2. Launch Godot
3. Import this project by opening the file **project.godot**
